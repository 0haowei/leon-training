# Leon Training V6.4 简洁卡片版

基于已交付 V6.3 增量升级，原 V6.3 目录和 ZIP 保留为源码备份。默认每个动作约74px，允许自然滚动，不为塞满一屏压缩可读性。

- 力量：动作名称、组数×次数、最多30字提示、独立打卡。
- 网球：按 JSON 顺序显示阶段、分钟数、开始时间及独立打卡。开始时间由事件起点与此前阶段时长相加得到；缺少阶段时长时不猜测后续开始时间。
- 点击名称或信息区展开图片、最多3条要点、错误和教学入口。
- 默认隐藏所有训练输入框。在“训练记录与备份”开启高级记录，可查看/填写组重量、次数及备注；不影响旧记录。
- 饮食仅使用 JSON 的营养目标与餐次，长说明折叠在“详细建议”。餐次摘要截短展示，完整内容仍可展开。
- 无合法 LEON_DATA 时显示原文和提示，不从自由文本生成动作或营养数字。现有普通备注仍需由日历管理端转换为协议。

## 部署

先在原网页导出 JSON 备份。解压 Leon_Training_V6.4_GitHub_Pages.zip，把内部文件和目录上传原仓库根目录并覆盖；不嵌套外层目录。等待 Pages 部署成功，联网关闭重开页面，确认“日历连接与设置 · V6.4”。不清除网站数据、不卸载PWA。

点击“日历连接与设置”可连接 Google 或手动刷新。授权有效期间前台每分钟、恢复前台时自动同步；关闭重开或令牌过期仍需重新连接。离线显示带时间标记的缓存。

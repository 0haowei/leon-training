# Leon Training V6.3 — Google Calendar 驱动

基于 GitHub `0haowei/leon-training` 检查时的最新提交 `41acfaf4b217899d9e1909fcbeda3f23441582cd` 增量升级。该提交页面标注 V6.1；本交付也兼容已知 V6.2 的本机记录格式。保留 PWA 外壳、导航、Google 只读连接、三类日历、JSON 导入导出；移除会与日历冲突的固定周计划。

## 使用

1. 升级前，在原网页导出训练记录 JSON。
2. 在原网址打开升级版，保存原 OAuth 客户端 ID，连接 Google，勾选网球训练、体能训练、饮食日历。
3. 让 ChatGPT 按 [日历协议](CALENDAR_PROTOCOL.md) 更新事件描述。可交给它 [日历更新指令](给ChatGPT的日历更新指令.md)。
4. 页面在线且授权有效时每分钟更新，返回前台和「立即刷新」也检查更新。已成功同步的日期可以离线查看。
5. 重量、完成状态和技术备注保存在本机；手机与电脑的训练记录不会自动互通，可用 JSON 转移。

只修改日历 JSON 就能改变动作、组数、次数、时长、餐次和营养目标，无需再次部署。未知动作也能显示基本卡片与记录字段，教学资料显示待补充。为新动作添加经过审核的专属图文/视频仍需更新资料库；不会错误匹配其他动作资料。

## 部署

解压部署 ZIP，将里面的文件以及 data/、assets/、icons/ 上传原仓库根目录，覆盖同名文件。不要嵌套外层文件夹。根目录必须直接有 index.html 和 sw.js。保留原 Pages 分支设置，等待 Actions 的部署成功，在原网址联网打开、关闭后重开，确认「日历计划 V6.3」。无需清除网站数据或卸载 PWA。

原地址：https://0haowei.github.io/leon-training/ 。同一浏览器、域名与安装环境可继续访问原记录。更换浏览器或设备需要导入备份。

无需构建或服务器。OAuth 客户端 ID 是公开应用标识，不是客户端密钥。仓库中不保存用户访问令牌、刷新令牌或客户端密钥。

## 同步边界

- 启动自动读取缓存并检查授权；当前页面已有有效令牌时联网同步。
- 完全关闭重开、刷新网页或令牌过期后，需要点击「连接 Google 日历」。访问令牌只在内存，不持久化或导出。
- 静态 GitHub Pages 不能安全持有服务器刷新令牌，也不能保证 iPhone 后台长期运行；本版不是全天候后台推送。长期无交互授权需要受保护的后端。
- 离线/失败/无授权显示缓存标记和该日期上次成功时间；无缓存日期显示无内容，不伪装为实时数据。
- 普通旧备注不再拆分动作，没有有效 JSON 时完整展示可读原文。须在日历端转换一次，不会使用固定模板填补。
